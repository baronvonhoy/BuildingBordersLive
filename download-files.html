Shapefiles, Databases, and User Guides

User Guide

The User Guide contains a detailed description of the project's methodology related to data entry, cleaning, processing, and limitations. It also includes an overview of the historical maps and primary source documents used to create the shape files and databases. Finally, the user guide provides a detailed appendix that describes the abbreviations used in each of the files. 
Download User Guide

Shapefiles and Datasets

The project created a series of shapefiles and datasets that are freely available for download. The shapefiles were created in ArcGis by digitizing historic maps and employment records. The datasets were created by digitizing employment records and are available for use with spreadsheet or database programs.
